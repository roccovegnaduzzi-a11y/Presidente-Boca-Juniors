# Boca Presidente

Herramientas para hacer crecer [bocapresidente.com](https://bocapresidente.com), el juego web donde sos presidente de Boca.

- [`bot-tiktok/`](bot-tiktok/README.md): arma videos del juego para TikTok (guion con IA y datos reales, grabación del juego, subtítulos para leer con tu voz y edición) y los manda a los borradores de la cuenta. Corre solo con GitHub Actions.
